# Kanchan Deshmukh — Personal Portfolio

Modern, interactive personal portfolio website showcasing data analytics projects, hackathon achievements, and technical skills.

## 🚀 Live Demo
Visit the live site: [portfolio-kanchan.vercel.app](https://portfolio-kanchan.vercel.app)

## 🛠️ Built With
- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Visuals & Animations:** HTML5 Canvas (interactive constellation animation), CSS3 Keyframes
- **Deployment:** [Vercel](https://vercel.com/)

## 📂 Featured Sections
- **Hero:** Interactive intro with resume download and social links
- **About:** Professional introduction and background
- **Tech Stack:** Core tools (Python, SQL, Power BI, Excel, C, Pandas, MySQL, Git)
- **Projects:** Data analysis, machine learning models, and full-stack MERN projects with direct GitHub links
- **Achievements:** Smart India Hackathon finalist recognitions and certifications
- **Contact:** One-click email and profile links

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Kanchan1903/portfolio.git

# Navigate into project directory
cd portfolio/my-protfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```
